# How we work — team rules

1. **Daily 15-min standup** — What I did, what I'll do, what's blocking me. Same time every day.
2. **main always works** — Branches per feature and pull request with one review. Nobody pushes directly to main.
3. **Contracts before code** — OpenAPI published on the 8th. If a contract changes, notify the group.
4. **Everything in English in the repo** — Code, commits, README and docs. Saves translating at the end.
5. **A single source of truth** — The battle plan page for tasks; Valentín and Vicente's Cherry Crisis scenario for numbers.
6. **Everyone writes their part of the docs** — Whoever builds a module writes its section in the technical document.
