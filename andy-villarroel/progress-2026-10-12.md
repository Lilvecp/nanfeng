### 3. Red team through the agent — r4-06

21 attacks through `Agent.handle_document`: 12 document injections on a clean invoice, 4 chat / exfiltration messages as WhatsApp or WeCom, 5 bank-detail swaps. **None moves money.** A control test checks that the clean invoice is paid, so the suite cannot pass by blocking everything. Finding kept in the self-assessment (K3): 8 document injections are only `suspicious`, so the agent continues with typed fields; it does not pay, but nothing blocks the run.

### 4. AI-generated label (CAC) — r4-11

The compliance docs claimed messages to Chinese importers were labelled AI-generated; the code did not do it. Now every collection reminder ends with 【本消息由AI生成 · NanFeng】 (or the English / Spanish label), the WeCom mirror in the cockpit shows it, and messages to the owner are not labelled. Tested.
